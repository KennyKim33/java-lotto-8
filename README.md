# 로또
## 프로젝트 소개
콘솔을 이용하여 로또 게임을 실행하는 프로젝트 입니다.  
사용자는 금액을 입력하여 로또를 구매하고, 당첨 번호와 비교하여 수익률을 확인할 수 있습니다.

## 주요 기능

### 1.로또 구매
- 구입 금액을 입력받아 로또를 자동으로 발행합니다.
- 1장 1000원이며, 입력 금액에 따라 매수가 결정됩니다.

### 2. 당첨 번호 입력
- 6개의 당첨 번호와 1개의 보너스 번호를 입력 받습니다.

### 3. 당첨 결과 확인
- 구매한 로또와 당첨 번호를 비교하여 당첨 통계를 출력합니다.
- 총 수익률을 계산하여 표시합니다.

---

## 실행 흐름

1. 구입 금액을 입력받습니다.
2. 구매한만큼의 로또가 발행됩니다.
3. 로또의 당첨 번호를 입력받습니다.
   (당첨 번호는 6개의 일반 번호와 1개의 보너스 번호로 이뤄져 있습니다.)
4. 당첨 번호와 비교하여 당첨 결과에 대한 수익률과 함께 통계를 제공합니다.

--- 

## 실행 결과 예시
```md
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능 구현 사항
### 입력 기능
- [x] 구입 금액을 입력받는다.

- [x] 당첨 번호를 입력 받는다.

- [x] 보너스 번호를 입력 받는다.

## 검증
- [x] 구매 검증
  - [x] 1000원 단위로 입력 되어야 한다.
  - [x] 구매의 최소 기준은 1000원이다.
- [x] 당첨 번호 검증
  - [x] 번호의 범위는 1 ~ 45 이다.
  - [x] 중복된 숫자가 없어야 한다.

- [x] 보너스 번호 검증
  - [x] 번호의 범위는 1 ~ 45 이다.
  - [x] 당첨 번호와 중복되지 않아야 한다.
### 출력 기능
- [ ] 구매한 로또 목록을 출력한다.
- [ ] 각 등수별 당첨 개수를 출력한다.
- [ ] 총 수익률을 계산하여 출력한다.
    - [ ] 수익률 = (총 당첨 금액 / 구입 금액) × 100
### 로또 발행 기능
- [x] 로또 번호를 자동으로 생성한다.
    - [x] 1~45 사이의 중복되지 않는 6개 숫자를 생성한다.
    - [x] 생성된 번호는 오름차순으로 정렬한다.
- [x] 입력 금액에 따라 로또 구매 매수를 계산한다.

### 당첨 확인 기능
- [ ] 각 로또에 대해 당첨 번호와 일치하는 개수를 확인한다.
- [ ] 보너스 번호 일치 여부를 확인한다.
- [x] 등수를 판정한다.
    - [x] 6개 일치: 1등 (2,000,000,000원)
    - [x] 5개 일치 + 보너스 일치: 2등 (30,000,000원)
    - [x] 5개 일치: 3등 (1,500,000원)
    - [x] 4개 일치: 4등 (50,000원)
    - [x] 3개 일치: 5등 (5,000원)


### 예외 처리
- [x] 잘못된 값 입력 시 `IllegalArgumentException`을 발생시킨다.
- [x] 에러 메시지는 `[ERROR]`로 시작한다.
- [ ] 예외 발생 시 해당 부분부터 입력을 다시 받는다.

### 구입 금액 입력 예외
- [x] 입력이 빈 값이거나 `null`인 경우
- [x] 숫자가 아닌 값이 입력된 경우
- [x] 구입 금액이 1,000원 미만인 경우
- [x] 구입 금액이 1,000원 단위가 아닌 경우

### 당첨 번호 입력 예외
- [x] 입력이 빈 값이거나 `null`인 경우
- [x] 숫자가 아닌 값이 포함된 경우
- [x] 번호가 쉼표(,)로 구분되지 않은 경우
- [x] 당첨 번호가 6개가 아닌 경우
- [x] 당첨 번호가 1~45 범위를 벗어난 경우
- [x] 당첨 번호에 중복이 있는 경우

### 보너스 번호 입력 예외
- [x] 입력이 빈 값이거나 `null`인 경우
- [x] 숫자가 아닌 값이 입력된 경우
- [x] 보너스 번호가 1~45 범위를 벗어난 경우
- [x] 보너스 번호가 당첨 번호와 중복된 경우
